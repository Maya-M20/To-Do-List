# My To-Do-List

## О проекте

**My To-Do List** — это веб-приложение для управления повседневными задачами. Оно позволяет создавать список дел, устанавливать сроки выполнения, отслеживать прогресс и организовывать задачи в удобном порядке.

Проект разработан с использованием нативных веб-технологий без применения сторонних JavaScript-фреймворков и CSS-библиотек.

## Функциональность

Приложение поддерживает следующие возможности:

- **Создание задач** — добавление новых задач с названием и датой выполнения.
- **Редактирование задач** — изменение названия и срока выполнения существующих задач.
- **Удаление задач** — удаление ненужных задач из списка.
- **Отслеживание выполнения** — возможность отмечать задачи как выполненные и возвращать их в статус невыполненных.
- **Фильтрация** — отображение всех задач, только выполненных или только невыполненных.
- **Поиск** — поиск задач по названию.
- **Сортировка по дате** — упорядочивание задач по сроку выполнения.
- **Drag-and-drop** — изменение порядка задач путём перетаскивания элементов списка.
- **Модальное окно** — редактирование задач в отдельном модальном окне.

## Технологический стек

В проекте используются:

- **HTML5** — базовая структура веб-приложения и семантическая разметка.
- **CSS3** — стилизация элементов интерфейса, Flexbox и адаптивная верстка.
- **JavaScript** — реализация логики приложения, обработка событий, динамическое создание и изменение DOM-элементов.

Дополнительные технологии и библиотеки не используются.

## Запуск проекта

1. Склонируйте репозиторий:
   ```bash
   git clone <repository-url>
   ```
2. Откройте папку проекта.
3. Запустите `index.html` в браузере.

## Цель проекта

Основная цель проекта — получить практический опыт разработки интерактивных веб-приложений с использованием JavaScript, научиться работать с DOM API, массивами, событиями и динамическим управлением элементами интерфейса.
